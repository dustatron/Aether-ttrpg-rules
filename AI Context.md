# AI Context

This vault contains the current rules for **The Arcane Aether** and archived drafts from earlier versions.

## Authority Order

When sources disagree, use this order:

1. The user's latest instruction.
2. [[Core Rules]], [[Character Creation]], [[Monsters]], and linked v4.5 notes marked `canonical: true`.
3. [[Open Questions]] for mechanics that are not settled.
4. Lore and brainstorm notes.
5. `archive/` only when researching history. Archived rules are never current authority.

## Current Terminology

Use **The Arcane Aether**, **Aether**, and **Arcanist**.

The earlier names **The Resonance**, **Resonance**, and **Attuner** appear in archived material. Do not restore them to current notes.

Use **player** for the real person at the table. Use **character** for the person in the game world.

## Editing Rules

- Preserve the designer's conversational voice and strange examples.
- Keep settled mechanics direct and concise.
- Do not invent rules to fill blank Perks or unfinished tables.
- Put a real unresolved mechanic in [[Open Questions]].
- Do not copy historical decisions from `archive/` into current rules without confirmation.
- Keep one canonical home for each rule. Link to it instead of repeating it.
- Preserve Obsidian wikilinks.
- Do not use em dashes.
