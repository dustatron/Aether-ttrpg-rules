# Core Rules

The Arcane Aether is a rules-light game about ordinary people who can reshape reality and must live with the cost.

For the premise and reading order, start with [[Start Here]]. To make a character, use [[Character Creation]].

Read the rules by topic:

1. [[Core Mechanics]]: Rolling dice, Luck, advancement, inventory, conditions, movement, and combat.
2. [[Casting Magic]]: Casting, Spell Tags, Magic Magnitude, magical healing, Exposure, and Mutation.
3. [[Magic Items and Dispersing Exposure]]: Creating, refilling, and using relics.
4. [[Dying and Recovery]]: Health, Scars, Fatigue, rest, and death.
5. [[Monsters]]: Building and running opposition.

For reference tables and worked monsters, see [[mutation-tables|Mutation Table]], [[wild-magic-table|Wild Magic]], [[Spell Tags]], and [[Bestiary]].
