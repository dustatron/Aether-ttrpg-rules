# CLAUDE.md Working Contract for The Arcane Aether Vault

This is an Obsidian vault for **The Arcane Aether**, a rules-light tabletop game in active design.

Read [[AI Context]] first. It defines the authority order, current terminology, and current reading set.

## Current Rules

Version **4.5** is current.

- [[Start Here]] contains the premise and navigation.
- [[Core Rules]] is the canonical engine.
- [[Character Creation]] and `rules/archetypes/` contain current character rules.
- [[Monsters]] and [[Bestiary]] contain current GM rules.
- [[Open Questions]] contains only unresolved v4.5 work.
- `archive/` is historical background, never current authority.

## Terminology

Use these current terms:

| Concept | Current term |
| --- | --- |
| Game and underlying reality | The Arcane Aether |

The Resonance and Attuner are archived terms. Do not use them in current notes.

## Status and Frontmatter

Current rules use:

```yaml
system: arcane-aether
status: current
version: 4.5
canonical: true
```

Use `status: draft` for unfinished material and `status: archived` for historical material. Do not mark an unresolved mechanic as current.

## Authoring Conventions

- Follow [AGENTS.md](AGENTS.md) for player and character terminology and the designer's voice.
- Use Obsidian wikilinks at the point where the reader needs them.
- Keep one canonical home for each rule. Link rather than duplicate.
- Use tables for comparable costs and results. Use lists for steps.
- Use periods, commas, or colons instead of em dashes.
- Preserve strange examples and humor.
- Do not invent rules to complete blank Perks or tables.
- Put unresolved mechanics in [[Open Questions]].
- Check heading anchors after renaming a heading.

## Before Saving an Edit

- Check every use of “you” and “your.” The player rolls and makes decisions. Their character casts, moves, takes damage, mutates, and dies.
- Compare the changed passage with surrounding prose.
- Verify that a wording edit did not change numbers, timing, permissions, costs, or outcomes.
- Check links and current terminology.
- Keep archived notes out of the live rules path.
